## How we work

- **Project autonomy:** Repository maintainers make technical decisions. The organization provides space for discovery and collaboration.
- **Creator ownership:** Code, documentation, and design belong to their developers or respective rights holders.
- **Listing is not certification:** Check each project's source, license, compatibility, and runtime risks independently.
- **Open participation:** You do not need organization membership to participate publicly. Permissions follow defined responsibilities.
- **Lightweight governance:** Routine work moves quickly; high-impact changes retain review, records, and a path to reversal.
