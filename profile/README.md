## 社区原则

- **项目自治：** 技术决定由各仓库维护者负责，组织提供发现与协作空间。
- **作者所有：** 代码、文档和设计的权利归各项目开发者或相应权利人。
- **收录不等于认证：** 请独立核对来源、许可证、兼容性和运行风险。
- **开放参与：** 公开参与不要求组织成员身份；权限只随明确责任授予。
- **轻量治理：** 常规工作快速推进，高影响事项保留审阅、记录与撤回路径。
